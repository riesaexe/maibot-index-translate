# 中文翻译 · Index-Translate

<img src="icon.png" width="112" alt="中文翻译插件图标">

MaiBot 插件，将聊天文字和图片里的文字翻译为简体中文。使用哔哩哔哩 [Index-Translate](https://index-translate.bilibili.com/) 服务，图片翻译返回回填中文的图片，回复引用原始消息。

## 使用

- 文字：`/rs 翻译 Hello, world!`
- 图片：发送图片并附上 `/rs 翻译`。
- 引用：引用文字或图片消息，发送 `/rs 翻译`。
- 自定义：在插件设置里将 `plugin.command` 改为 `/tr`，重载插件后使用 `/tr Hello` 或附图 `/tr`。旧命令不再作为别名保留。

命令按字面量匹配；单词之间可以有多个空白，不需要配置正则表达式。最多 40 个字符，不能留空或包含换行。

## 安装

兼容范围：MaiBot `1.3.10–1.3.99`，插件 SDK `2.12.0–2.12.99`。需要宿主支持 Python 3.12 或更新版本。

从插件中心安装，或将本仓库克隆到 MaiBot 的 `plugins/` 下独立目录，然后重新加载插件。宿主会读取 `_manifest.json` 安装 Python 依赖；不要将整个 MaiBot 仓库复制进插件目录。

```bash
git clone https://github.com/riesaexe/maibot-index-translate.git plugins/maibot-index-translate
```

本次首次公开版本为 **1.6.0 预发布**，图片复杂场景仍在改进。

## 设置

由 MaiBot 插件设置页生成和维护配置，无需修改机器人全局模型设置。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| `plugin.enabled` | `true` | 启用翻译 |
| `plugin.command` | `/rs 翻译` | 完整触发命令，修改后重载插件生效 |
| `plugin.model` | `Index-Translate-35B-A3B` | 可选同服务的 `Index-Translate-9B`、`Index-Translate-2B` |
| `plugin.comic_detector` | `auto` | `auto` 自动识别漫画；`on` 强制漫画模式；`off` 普通图片模式 |
| `plugin.font_path` | 空 | 留空选择系统中文字体，也可指定已安装的中文字体文件路径 |

旧版配置的其他字段无需为自定义命令而改变；新增字段未填写时使用默认命令。配置版本为 `1.3.0`，使用宿主的标准配置规范化机制。

## 图片处理与性能

- 普通图片使用 RapidOCR 定位，再将原始文字图块交给翻译服务读取；斜拍手写页保留文字方向。
- 漫画使用 Comic Text Detector 定位及生成文字掩膜；日文台词用 Manga OCR 识别后交给原翻译服务。
- 首次漫画检测下载约 95 MB 模型，首次日文 OCR 下载约 444 MB 模型。需要访问 GitHub Releases 和 Hugging Face；下载后的模型缓存在插件 `.models/` 中，不随仓库发布。
- 首次加载日文模型较慢，之后复用模型；不同图片仍需重新识别和请求服务。
- 最多 3 路区域翻译并发；相同图片、模型和字体配置在 10 分钟内可复用成功译图，缓存仅在内存，最多 4 张、24 MiB。重载插件或更新配置会清空缓存。
- 每次最多 4 张图片、12000 个文字字符；单图最多 10 MB、2000 万像素。
- 未能可靠辨认的部分保留原文并提示，不代表已完成全部翻译。

图片文字会发送至哔哩哔哩翻译服务；日文 OCR 和文字定位在本地执行。不要用此插件发送不适合交给该外部服务处理的内容。

## 已知限制与验证

自定义命令注册、直接附图、引用回复、并发、缓存、背景与手部保护均有回归验证。但功能测试通过不等于每张图片的视觉质量通过。

最近一次 1.5.3 图片回归覆盖 24 张原始输入：9 张通过、7 张需改进、8 张未通过；另测 3 张历史故障译图。1.6.0 主要新增可配置命令和发布元数据，没有宣称修复这些视觉问题：

- 密集完整界面可能因为中文字数超出原区域而无法出图。
- 部分电子界面会被当作纸张处理，出现楷体、层级变化、图标被转成文字或局部文字跨区。
- 花体占位文本存在解释性输出和字形失真；原字体纹理不能精确复刻。
- 个别旋转小字仍会漏译，手绘边框可能受擦字影响。
- 已经翻译出错或被擦坏的图片，不能靠再次翻译恢复原画；应使用未处理原图。
- 翻译 API 的可用性、响应速度和结果受服务端状态影响，插件不提供可用性保证。

QQ PC 与移动端的引用显示还受到客户端版本和适配器行为影响。
